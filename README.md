# 🎮 Dashboard de Vendas - Xbox Game Pass

## 📌 Sobre o Projeto
Este projeto tem como objetivo desenvolver um **Dashboard Executivo de Vendas** utilizando **Microsoft Excel**, transformando dados brutos em informações visuais estratégicas para apoio à tomada de decisão.

O dashboard foi construído com foco em:
- Organização visual dos dados;
- Criação de KPIs estratégicos;
- Análise de faturamento;
- Visualização gráfica de desempenho de vendas;
- Geração de insights de negócio.

---

# 📊 Objetivos da Análise

O dashboard responde às seguintes perguntas de negócio:

### ✅ Pergunta de Negócio 1
Qual o faturamento total de vendas de planos anuais?

### ✅ Pergunta de Negócio 2
Qual o faturamento total de planos anuais separado entre:
- Auto renovação;
- Sem auto renovação.

### ✅ Pergunta de Negócio 3
Qual o total de vendas de assinaturas do EA Play?

### ✅ Pergunta de Negócio 4
Qual o total de vendas de assinaturas do Minecraft Season Pass?

---

# 📈 Insights Gerados

Além das perguntas principais, o dashboard apresenta análises complementares:

- Receita total por tipo de plano;
- Evolução mensal do faturamento;
- Distribuição de assinaturas com auto renovação;
- Indicadores executivos (KPIs);
- Comparação entre categorias de assinatura.

---

# 🖥️ Estrutura do Arquivo Excel

O arquivo `.xlsx` está dividido nas seguintes abas:

| Aba | Descrição |
|---|---|
| **Bases** | Dados brutos utilizados na análise |
| **Cálculos** | Métricas, KPIs e tabelas auxiliares |
| **Dashboard Final** | Painel executivo com gráficos e indicadores |

---

# 📊 Recursos Utilizados no Dashboard

## KPIs
- Faturamento de Planos Anuais;
- Receita EA Play;
- Receita Minecraft Pass;
- Receita com Auto Renovação.

## Gráficos
- 📉 Gráfico de Linha → Evolução mensal do faturamento;
- 📊 Gráfico de Barras → Receita por plano;
- 🥧 Gráfico de Pizza → Distribuição de auto renovação.
